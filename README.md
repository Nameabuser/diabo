# Diabo

Blood-sugar logging PWA for iPhone home screen.

- **Scan meter** - photo of a 7-segment meter display is read on-device (no uploads, no network)
- **Number pad** - big pad, quick save
- **Voice** - "137 before lunch" (Web Speech API, where supported)

Data stays on the device (localStorage). Tracker only - not medical advice.

Live: https://nameabuser.github.io/diabo/
